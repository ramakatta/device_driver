Classic ARM SoC (e.g. STM32MP2):
BootROM → TF-A BL1 → TF-A BL2 → BL31 → U-Boot → Linux

Raspberry Pi 4:
GPU firmware (start4.elf) → TF-A BL31 (armstub8.bin) → U-Boot → Linux

+-----------------------------+
| BCM2711 Boot ROM (GPU)      |
| - starts from EEPROM        |
+-----------------------------+
              |
              v
+-----------------------------+
| EEPROM bootloader           |
| - initializes basic HW      |
| - loads start4.elf          |
+-----------------------------+
              |
              v
+-----------------------------+
| start4.elf (VideoCore)      |
|                             |
| - initializes DRAM          | <---- DRAM INIT HERE
| - configures clocks         |
| - configures power domains  |
| - loads ARM firmware        |
| - loads DTB                 |
| - loads BL31                |
| - loads U-Boot              |
+-----------------------------+
              |
              v
+-----------------------------+
| TF-A BL31 (EL3)             |
|                             |
| - assumes DRAM is ready     |
| - initializes EL3 runtime   |
| - installs PSCI             |
| - patches DTB               |
+-----------------------------+
              |
              v
+-----------------------------+
| U-Boot BL33                 |
|                             |
| - assumes DRAM is ready     |
| - loads Linux kernel        |
| - prepares boot arguments   |
+-----------------------------+
              |
              v
+-----------------------------+
| Linux kernel                |
|                             |
| - uses initialized DRAM     |
+-----------------------------+



Build U-boot

git clone https://gitlab.denx.de/u-boot/u-boot
cd u-boot
git checkout v2023.01
make rpi_4_defconfig
make menuconfig
make -j$(nproc)
ls -lh u-boot.bin
# u-boot.bin  603K

Build TF-A

git clone https://git.trustedfirmware.org/TF-A/trusted-firmware-a.git
cd trusted-firmware-a
git checkout v2.10.0

make \
  CROSS_COMPILE=aarch64-linux- \
  PLAT=rpi4 \
  RPI3_PRELOADED_DTB_BASE=0x2600000 \
  PRELOADED_BL33_BASE=0x80000 \
  SUPPORT_VFP=1 \
  DEBUG=1 \
  all
trusted-firmware-a/build/rpi4/debug/bl31.bin

sudo tee /mnt/config.txt << 'EOF'
arm_64bit=1
enable_uart=1
dtoverlay=disable-bt
armstub=bl31.bin
kernel=u-boot.bin
device_tree_address=0x2600000
EOF

Config.txt in bootfs 0 partition

# Run in 64-bit mode
arm_64bit=1
enable_uart=1
enable_gic=1
dtoverlay=disable-bt
armstub=bl31.bin
# Force the Pi to boot your U-Boot binary instead of the Linux kernel
kernel=u-boot.bin
device_tree_address=0x2600000
